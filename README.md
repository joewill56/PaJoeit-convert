# PAJOEIT CONVERT

**Free, private, in-browser image workspace.** Convert, compress, and resize images (WebP ↔ PNG ↔ JPG) entirely client-side — zero server uploads, zero signup.

🌐 **Live:** [pajoeit-convert.pages.dev](https://pajoeit-convert.pages.dev)

---

## ✨ Features

- **Format conversion** – WebP, PNG, JPG (to/from any combination)
- **Compression presets** – None / Light / Balanced / Max
- **Target size engine** – Compress to an exact KB target (e.g. 100 KB, 50 KB)
- **Image resizing** – Width × Height with locked aspect ratio, or scale by %
- **Batch processing** – Up to 50 images at once with ZIP download
- **100% private** – All processing happens in your browser; no data ever leaves your device
- **Multilingual** – English, Spanish, French, Portuguese (and more via i18n)
- **PWA-ready** – Installable, works offline

## 🚀 Local Development

### Prerequisites

- **Node.js** ≥ 20
- **npm** ≥ 10

### Install & Run

```bash
git clone https://github.com/your-org/pajoeit-convert.git
cd pajoeit-convert
npm install
npm run dev
```

The dev server starts at **http://localhost:3000**.

---

## 🏗 Build

```bash
npm run build
```

This runs `vite build` followed by `tsx scripts/prerender.mjs`, which:
1. Generates pre-rendered HTML for each route (for SEO / static hosting)
2. Regenerates `dist/sitemap.xml` and `dist/robots.txt`

> **Note:** The prerender script requires `GEMINI_API_KEY` to be set if any AI-powered routes are included.

---

## ☁️ Cloudflare Deployment

### Workers (recommended)

```bash
npx wrangler deploy
```

Ensure `wrangler.toml` references the `dist/` output directory.

### Pages

Upload the `dist/` folder via the Cloudflare Pages dashboard, or use:

```bash
npx wrangler pages deploy dist
```

The `public/_redirects` file handles SPA routing (`/* → /index.html 200`).
The `public/_headers` file sets correct `Content-Type` for `sitemap.xml` and `robots.txt`.

## 🌐 Environment Variables

Copy `.env.example` to `.env` and fill in:

```bash
cp .env.example .env
```

| Variable | Description |
|----------|-------------|
| `GEMINI_API_KEY` | Google Gemini API key (used by prerender script for AI-generated meta) |
| `APP_URL` | Canonical app URL (used for self-referential links) |

> `.env` is gitignored. Never commit secrets.

---

## 🗺 SEO & Sitemap

The sitemap is generated by `scripts/prerender.mjs` during the build. After changing `BASE_URL` or adding new routes, run:

```bash
npm run build
```

Or, to update only the sitemap/robots in `public/` without a full build:

```bash
sed -i 's|old-domain.pages.dev|pajoeit-convert.pages.dev|g' public/sitemap.xml public/robots.txt
```
